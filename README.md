# Frontend Mentor - 3-Column Preview Card Component

A responsive 3-column preview card component built as part of the [Frontend Mentor](https://www.frontendmentor.io/) coding challenges.

## Overview

This project presents three vehicle categories: Sedans, SUVs, and Luxury. Each card includes an icon, a heading, a short description, and a "Learn More" button.

The goal was to recreate the provided design using HTML and CSS while practising layout, spacing, typography, and responsive web design.

## Features

- Three distinct vehicle category cards.
- Different background colours for each card.
- Responsive layout for desktop and mobile screens.
- Styled typography and card spacing.
- Hover states for interactive elements, where implemented.

## Built With

- HTML5
- CSS3
- CSS Flexbox

## What I Learned

While working on this project, I practised:

- Using Flexbox to arrange cards.
- Applying background colours, padding, and border radius.
- Controlling paragraph width and text wrapping.
- Working with typography and icons.
- Developing responsive layouts for different screen sizes.
